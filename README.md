# UDP File Transfer 

Легковесная клиент-серверная утилита на языке C для передачи бинарных и текстовых файлов по протоколу UDP с верификацией целостности через SHA-256.

--version 1.1

---

## В чём идея?

Передача файлов по TCP создает накладные расходы на постоянный handshake, поддержание соединений и управление окном перегрузки. Данный проект реализует простую и быструю передачу файлов через ненадежный транспорт **UDP**, решая ключевую проблему потерь и повреждения данных с помощью криптографической сверки контрольной суммы на лету. Так же алгоритм будет дорабатываться для более надежной отправки по сети без потери времяэффективности. 
Сам проект был написан, просто чтобы вспомнить C и иметь прикольную тулу для взаимодействия с сервером. В планах развивать проект для более удобного взаимодействия, увеличения надежности, повышения эффективности и фикса багов.

### Ключевые особенности
- **Zero-RAM Footprint (Streaming):** Файл читается, отправляется, записывается и хэшируется на лету фиксированными блоками (`BUFFER_SIZE`). Программа потребляет минимум оперативной памяти (~1 КБ) независимо от размера файла.
- **Интеграция SHA-256:** Локальный расчет хэша происходит параллельно с передачей данных — файл не перечитывается с диска дважды.
- **Безопасная обработка путей:** Благодаря `basename`, клиент может читать файл по любому относительному или абсолютному пути, а сервер сохраняет файл с чистым именем (`recv_<filename>`).
- **Демонизированный сервер:** Сервер обрабатывает прерывания (`SIGINT`), освобождает порт и готов циклично принимать новые файлы от разных клиентов.

## Как устроен протокол?

Передача состоит из трех последовательных фаз:

```text
 Client                                                 Server
   │                                                      │
   │ 1. Имя файла: "archive.zip"                          │
   ├─────────────────────────────────────────────────────►│ -> fopen("recv_archive.zip", "wb")
   │                                                      │
   │ 2. Потоковая передача чанков (Pack):                 │
   │    [seq: 0, size: 1024, data...] ───────────────────►│ -> fwrite() & sha256_append()
   │    [seq: 1, size: 1024, data...] ───────────────────►│ -> fwrite() & sha256_append()
   │    ...                                               │
   │    [seq: N, size: 0, marker]     ───────────────────►│ -> fclose(), sha256_finalize()
   │                                                      │
   │ 3. Контрольная сумма (SHA-256 hex):                  │
   │    "e3b0c44298fc1c149afbf4c8996fb92427ae41e464..."  │
   ├─────────────────────────────────────────────────────►│ -> strcmp(local, remote)
   │                                                      │    [OK] / [CORRUPTED]
```

## Сборка
Для сборки требуется gcc и make
```text
make
```
Очистка бинарников
```text
make
```
## Использование
Сервер
```
./server <port>
```
Клиент
```
./client <port> <ip-адрес> <путь-к-файлу>
```
